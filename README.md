# Unciv 悬浮购买助手

给现有原版Unciv增加外部悬浮批量购买入口，不包含游戏，不替换原版APK，不修改存档。预览版0.1.0，面向荣耀Magic7 / Android16，最低Android11。

这是独立辅助工具，不是Unciv普通规则模组。安装到手机后，在系统设置中由用户手动启用无障碍；不需要Root。只操作包名`com.unciv.app`的原版Unciv。内置ML Kit中文/英文OCR模型，截图只在内存中识别，不保存、不上传；合并后的Manifest移除网络权限。

## 安装与首次校准

1. 用手机浏览器下载APK，交给安卓系统安装，不能通过游戏“从URL下载”安装。
2. 打开“Unciv 购买助手”，阅读用途说明，手动开启对应无障碍服务。若MagicOS提示受限设置，先到该应用信息的右上角菜单允许受限设置，再开启无障碍。
3. 在助手中点击“显示悬浮工具条”，自行进入原版Unciv自己的城市。展开“等待中的项目”，保持横屏。可拖动工具条第一行移动位置。
4. 点击“校准1/5”，框选完整队列文字列，包括“当前项目”标题和所有等待项目的名字，避开左侧图标、右侧移动/删除按钮。队列超出屏幕时助手会尝试滚动拼接。逐步记录城市名文字区域、带黄色金币图标的购买按钮、金币确认窗口中“你确定用…购买…吗？”整句话，以及窗口右下角购买确认按钮。调整游戏和打开示例弹窗须自己操作；框选只记录位置，不替你确认购买。
5. 完成5项校准后，手动取消示例购买窗口。点击“预检”，核对完整队列清单与重复项目数量；错漏就取消并重新校准。
6. 点击“购买”，核对清单后勾选确认，才会按原版界面逐项处理。单次默认预算10万金币，可在助手主界面调整。

## 行为

原版决定价格、折扣、金币扣除和放置结果。助手只点金币购买，不绕过科技、资源、金币、奇观或单位放置限制。无金币购买入口或按钮没有打开购买窗口的项目会跳过。确认窗口里的名字、完整金额、黄色金币证据和确认按钮文本必须匹配。确认点击不重试；每次确认后重新读取队列，与预期删除一项的结果比较。队列意外变化、城市改变、离开原版游戏、触摸中断、截图/识别失败就停止。最后一项购买后游戏自动补入的新项目不继续买。随时点击“停止”。

跨页识别利用相邻页面重叠拼接，连续重复名称或OCR错漏可能造成清单不完整，因此每批必须由用户核对完整清单和数量。最多40项、15页，超限停止。字体、屏幕比例、语言、主题改变需重新校准。金币颜色证据依赖原版黄金币图标；自定义主题不保证支持。先用2个不同的普通建筑试运行，再扩大队列。购买单位仍需满足原版放置限制。

最近结果中的“确认价格累计”是助手已尝试确认的原版弹窗金额合计，不是读取存档后的实际金币差额；若确认后状态不明，请以游戏为准，不要直接重复执行。

包含独立识别策略单元测试、Android编译、Lint、APK签名与权限校验。尚未完成用户Magic7实机的截图、OCR、校准及实际购买验证，不宣称已实机成功。这是待校准预览版。
